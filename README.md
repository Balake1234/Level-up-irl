# AI Fitness Coach Program

This is a Flutter scaffold for the AI Fitness Coach app.

## Setup

1. Install Flutter: https://flutter.dev/docs/get-started/install
2. Add Flutter to PATH and restart VS Code.
3. Open this folder in VS Code.

## Tasks

Use VS Code tasks or terminal commands:

- `flutter pub get`
- `flutter pub run flutter_launcher_icons:main`
- `flutter run -d chrome`

## Quick test steps

1. Open `lib/main.dart`
2. Run the app
3. Enter name, age, fitness level, and goal
4. Confirm that the workout plan screen appears
